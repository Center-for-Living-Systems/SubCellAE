## Project Overview
SubCellAE: semi-supervised convolutional autoencoder for focal adhesion (FA) morphology
analysis. Primary data: 32×32 paxillin channel patches from vinculin-tagged cells (vinc
dataset). Downstream tasks: FA-type classification (5 classes: Nascent Adhesion / focal
complex / focal adhesion / fibrillar adhesion / No adhesion) and position classification
(4 classes).

## Model Types

### `semisup`
Joint AE + dual classification heads (FA-type + position). Training loop:
`train_semisup_ae()` in `autoencoders.py`. Key AEConfig fields:
- `warmup_epochs`: recon-only phase before cls heads activate (0 = no warmup)
- `weight_decay`: Adam L2 (0 = no regularisation)
- `semisup_lr_scheduler_patience`: ReduceLROnPlateau patience (0 = disabled)
- `min_epochs_for_best`: best-checkpoint tracking starts at this epoch (0 = use final)
- `early_stopping_patience`: 0 = run all epochs

### `contrastive`
NT-Xent contrastive AE with projector head (12→48→8). Latents CSV has both `z_*`
(encoder output) and `p_*` (projector output) columns.

## Training Strategies (config/training_strategies/)

| Strategy | Epochs | weight_decay | warmup_epochs | lr_scheduler | checkpoint |
|----------|--------|-------------|---------------|--------------|-----------|
| `0322` | 200 | 0 | 0 | none | final (min_epochs_for_best=0) |
| `0324` | 500 | 1e-4 | 0 | none | after ep 200 |
| `mar30` | 500 | 1e-4 | 200 | none | after ep 200 |
| `final` | 500 | 1e-4 | 200 | cosine→1e-5 | after ep 200 |

**Key finding:** `0322` gives best FA-type classification despite overfitting.
**Why:** Classification loss active from epoch 1 → encoder shaped for FA discrimination
from the start. Strategies with warmup=200 pre-train like a conAE (visual clustering,
no class info), then cls heads must overcome that inertia.
**Confirmed by:** ConAE experiment — 0322 conAE is more clustered than default but FA
classes still mixed (no label supervision in NT-Xent = same problem as warmup phase).

`_to_unique_id()` in `classification_pipeline.py` converts patch filenames
(`condition_f...`) → label CSV format (`condition-f...`) for the join.
