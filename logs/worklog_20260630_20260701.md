### Architecture clarification
- 2ch models use joint convolution: `Conv2d(no_ch=2, 32, 3×3)` — both channels
  share the same 12-dim latent from the first layer (not independent encoders)
- 2ch augmentation: same geometric transform (rotation + translation) applied to
  both channels simultaneously via a single `affine_grid + grid_sample` call
- 2ch models use pre-extracted 32×32 patches (no 58×58 enlarged context crop);
  baselines (ch3, 2ch) have no augmentation at all — plain AE on stored patches

### UMAP on z_proj
- Confirmed: current UMAP uses `z_` columns (encoder output / z_recon)
- New script `regen_zproj_analysis.py`: fits UMAP + KMeans on `p_` columns
  (projector head output, 8-dim); falls back to z_ for baselines without a projector
- New PPT script `make_actin_vs_pax_ppt_zproj.py`: imports shared helpers from
  base PPT script, overrides only UMAP/cluster path functions
- Generated `slides_actin_vs_pax_zproj.pptx` (20 slides) — identical structure,
  z_proj UMAP/clusters throughout
