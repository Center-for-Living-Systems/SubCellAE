## 3. Experiment Design

### 3.1 Label Efficiency Benchmark Protocol

- **5-fold stratified CV × 5 repeats** per budget point (180 jobs total per dataset per label set)
- **Budgets (B2/DS2/DS3):** 10, 20, 25, 50, 75, 100, 150, all  
- **Budgets (B12 DS1 SupCon):** 10, 25, 50, 75, 150, 400, 750, all (reduced from 12-point list to save compute; 400 is new)
- **Training:** SupCon-AE retrained **from scratch** with only the budget-n labeled patches (cold-start); this is the hard but realistic protocol
- **Classifier (SupCon):** logistic regression on frozen z-latents after training
- **Classifier (CP/ilastik):** LightGBM (default) or logistic regression on precomputed features
- **Metric:** balanced accuracy on held-out fold

> **Key distinction vs. old s1v3 efficiency test:** The old test used a *fixed, fully-trained* SupCon model and only varied the downstream classifier budget. That reaches ~93–95% at n=75. The new protocol re-trains SupCon from scratch at each budget — a more realistic cold-start scenario that reaches ~65–80% at n=75.

### 3.2 FA4 4-Class Classification

- **Labels:** 4-class FA subtype (Nascent Adhesion, Focal Complex, Focal Adhesion, Fibrillar Adhesion), B1 labels only (~1,042 patches of vinc ctrl+ycomp)
- **Models compared:** SupCon-AE (lat=12/proj=8), CellProfiler features, ilastik features
- **New experiment:** SupCon-AE lat=32/proj=16, B1+B2 combined labels (3-model ensemble v0/v1/v2) — *training in progress*

### 3.3 proj_dim Ablation (pd8 vs pd16, DS2)

Tested whether increasing the projection head dimension from 8 to 16 meaningfully changes downstream balanced accuracy on DS2. Result: no consistent winner; differences are within noise (±0.03 at most).

## 7. Key Takeaways

1. **Handcrafted features dominate SupCon-AE in the cold-start LE regime.** CP+logreg reaches 0.88–0.98 at n=10–25 on DS2/DS3. SupCon-AE needs 300+ patches to be competitive on DS1.

2. **Logreg is better than LightGBM for SupCon latents** (linearly organized space); logreg also beats lgbm for B12 combined labels where folds are harder.

3. **B12 combined labels make the LE task harder on DS1** (more patches, more diverse folds from both annotators). CP lgbm drops ~4 pp at "all" budget (0.96 → 0.92). Logreg recovers most of the gap. **Hypothesis:** SupCon-AE should benefit more from B12 than CP/ilastik because the richer labeled set gives better contrastive signal, potentially closing the gap to CP/ilastik at mid-range budgets (50–400). This is the primary open question for the DS1 B12 SupCon jobs.

4. **B12 on DS2 adds almost nothing** — only 33 extra patches from the same 4 ctrl frames; B2 alone already near-saturates performance.

5. **pfak (DS2) is the "easiest" dataset** — adhesions are highly separable even at n=10. SupCon-AE has no room to demonstrate label efficiency advantage here.

6. **proj_dim has no effect** on downstream classification (pd8 ≈ pd16).

7. **FA4 4-class ceiling is ~0.60** for ilastik+logreg with current label set. SupCon-AE at lat=12 does not reach this. Lat=32 + B1+B2 result pending.
